### 바꿀 것 7개 (토큰·공용 부품에서 한 번 바꾸면 전 화면에 퍼진다)

1. **표면** — 라이트: 바탕 `#F6F7F9`, 패널 `#FFFFFF`, 보조 면 `#F0F2F5`, 경계 `#DDE1E6`. 다크: 바탕 `#101216`, 패널 `#171A20`, 보조 면 `#1E222A`, 경계 `#303640`. 일반 패널 그림자 **없음**. 그림자는 대화상자·팝오버·알림만.
2. **모서리·중첩** — 패널 `6px`, 버튼·입력·흐름 노드 `4px`, 라벨 `2px`. 원형은 상태 점·아바타만. 패널 안의 목록 항목은 배경 없음·모서리 0·행 사이 `1px` 구분선(카드 안 카드 금지).
3. **선택·포커스** — 선택 면 라이트 `#EAF0F8` / 다크 `#202D40`. 목록 선택은 왼쪽 `2px` 강조선, 노드 선택은 `1px` 강조색 테두리만. 글로우·이중 테두리·광택 제거. 포커스는 키보드일 때만 `2px` outline, offset `2px`.
4. **글자** — 크기 `12 / 13 / 14 / 18 / 28` 다섯 단계(보조·표 / 보조 본문 / 본문 / 페이지 제목 / 핵심 수치). 행간 본문 `1.5`, 제목·수치 `1.25`. 굵기 `400 / 500 / 600`만. 본문·보조색 라이트 `#20252D / #596273`, 다크 `#E7EBF0 / #A4ADBB`.
5. **상태·건수** — 건수는 배경 없는 `12px` 숫자. 상태는 `6px` 점 + `6px` 간격 + 글자. 색 면은 위험 라벨만(`2px 6px` 패딩, 모서리 `2px`). 알약 배지 금지.
6. **행동 버튼** — 높이 `32px`, 좌우 `12px`, 글자 `13px/500`, 간격 `8px`. 위반·예외 인정·오탐 세 판단은 **같은 중립 테두리 버튼**(색으로 정답을 암시하지 않음). 설명은 버튼 아래 `12px` 한 줄, 단축키는 배경 없는 숫자. 채운 강조 버튼은 화면당 주 행동 하나.
7. **밀도·선·알림** — 간격 `4 / 8 / 12 / 16 / 24`. 패널 안쪽 `16px`, 패널 사이 `12px`, 표 행 최소 `40px`, 표 머리 `36px`. 흐름도 연결선 `1px` 실선(라이트 `#AAB2BF`, 다크 `#626D7D`), 배포 루프만 점선. 알림은 오른쪽 아래, `13px`, 모서리 `4px`.

## 작업 나누기 (디자인 ↔ API 연동)

| 맡는 쪽 | 고치는 파일 |
|---|---|
| 디자인 | `src/styles/`, `src/ds/`, `src/shell/*.module.css`, `src/features/**/*.module.css`, 각 화면의 `*.tsx`(그리기) |
| API 연동 | `src/api/`, `src/domain/`, `src/features/*/model.ts`, `api/`(Vercel 함수) |

- 화면 파일(`Board.tsx`, `Review.tsx`, `FalsePositives.tsx`, `Insights.tsx`)은 데이터·동작을 `model.ts` 의 훅(`useBoardModel` 등)에서 받는다. 디자인 작업은 훅이 돌려주는 값과 동작을 그대로 쓰고, 새 데이터가 필요하면 연동 쪽에 요청한다.
- 둘 다 **main 에 바로 반영**한다(고정 주소 https://web-ib-2c2f.vercel.app 가 늘 최신). 올리기 전에 `git pull --rebase origin main`, `npx tsc -b && npm run build`. 커밋에 Claude 표기를 넣지 않는다.
