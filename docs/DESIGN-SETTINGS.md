# AI 누리 보안 — 디자인 설정 (2026-11-05)

정보보호팀이 매일 쓰는 판단 도구다. 화면에 먼저 보여야 하는 것은 사건, 상태, 판단 기록이다.

- **테마**: 다크 하나뿐이다. 라이트 테마와 테마 바꾸기는 없다.
- **기준 화면**: 데스크톱 1440px. 모바일은 깨지지 않을 정도만 맞춘다.
- **바탕**: 부품·면·모서리는 Devs(UNS) 디자인 시스템에서 가져왔다. 강조색과 글자는 우리 기준이다.
- **값의 출처**: `src/styles/tokens.css`(토큰), `src/ds/`(공용 부품), `src/shell/`(사이드바).

## 1. 원칙

1. **구조는 면으로 나눈다.** 패널은 테두리 없이 `surface` 면만 쓴다. 선은 표 행과 구역을 나눌 때만 쓴다.
2. **파랑(시그널 블루)은 세 곳에만 쓴다.**
   - 고른 것: 옅은 강조 면과 왼쪽 2px 막대.
   - 화면당 주 행동 하나: 채운 버튼.
   - 포커스.

   사이드바, 탭, 필터, 차트에는 파랑을 쓰지 않는다.
3. **글자색은 사실상 두 단계**다. 값·문장은 `fg`, 메타·라벨은 `mute`로 쓴다.
4. **판단에 쓰지 않는 정보는 지우거나 `title`로 접는다.** 데이터 출처('예시 데이터' / '서버 N건')는 사이드바 한 곳에만 둔다.
5. **보안팀은 원문을 보지 않는다.** 화면에는 가린 값만 보여 준다.
6. **판단 버튼 셋(위반 · 예외 인정 · 오탐)은 같은 모양**으로 둔다. 색으로 정답을 암시하지 않는다.
7. **움직임은 위치 전환과 나타남만** 쓴다. 길이는 120~320ms다.

## 3. 글자

글꼴은 **Pretendard Variable**(자체 호스팅)이다. 숫자에는 `tabular-nums`를 켠다. 한글은 낱말 단위로 줄을 바꾼다(`word-break: keep-all`).

| 토큰 | 크기 | 쓰는 곳 |
|---|---|---|
| `--t-12` | 12 | 시각, 단축키, 숫자 알약 (이보다 작게 쓰지 않는다) |
| `--t-13` | 13 | 표 보조, 부가 설명, 작은 버튼, 메타 |
| `--t-14` | 14 | 본문, 표 셀 |
| `--t-15` | 15 | 이름, 판단 버튼 제목 |
| `--t-16` | 16 | 구역·패널 제목, 보낸 문장 |
| `--t-18` | 18 | 처리 패널 제목 |
| `--t-20` | 20 | 상세 제목 |
| `--t-22` | 22 | 화면 제목 |
| `--t-28` | 28 | 핵심 수치(흐름도 노드, 현황 수치, PC 적용) |

**굵기는 세 가지만** 쓴다. 700과 800은 쓰지 않는다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--w-body` | 400 | 본문 |
| `--w-label` | 500 | 버튼, 라벨, 칩, 표 머리, 목록 이름 |
| `--w-title` | 600 | 화면·상세·구역 제목, 판단 버튼 제목, 핵심 수치, 채운 버튼 |

줄 간격은 본문 1.5, 제목 1.3이다. 600은 화면당 3~4덩어리를 넘기지 않는다.

## 4. 간격 · 모서리 · 높이 · 깊이

- **간격**(4pt 단위)
  - 토큰: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 36 · 48`
  - 화면 안쪽 여백 24, 구역 사이 24, 패널 안 16~20, 묶음 안 8이다.
- **모서리**(Devs 단계)

  | 토큰 | 값 | 쓰는 곳 |
  |---|---|---|
  | `--r-xs` | 2 | 가장 작은 부품 |
  | `--r-sm` | 6 | 작은 버튼, 라벨 |
  | `--r-md` | 12 | 버튼, 입력, 상자 |
  | `--r-xl` | 16 | 패널 (최대) |
  | `--r-full` | — | 상태 점, 칩, 토글 |

- **누르는 것의 높이**

  | 토큰 | 값 | 쓰는 곳 |
  |---|---|---|
  | `--ctl-xs` | 28 | 표 안 버튼·선택 |
  | `--ctl-sm` | 32 | 작은 버튼, 사이드바 항목 |
  | `--ctl-md` | 40 | 기본 버튼·입력 |

- **아이콘**: lucide, 선 굵기 1.5. 크기는 16(글자 옆)과 20(메뉴) 두 가지만 쓴다. 아이콘을 둥근 칸에 넣지 않는다.

## 5. 부품 (`src/ds`)

### 버튼 `Button` / `LinkButton`

모든 변형은 기본 → 올림 → 누름 → 비활성의 4단계 상태를 가진다. 비활성은 회색 면에 흐린 글자로 보인다.

| variant | 모양 | 쓰는 곳 |
|---|---|---|
| `now` | `--acc-fill` 채움, 흰 글자 600 | **화면당 주 행동 하나** (서명 후 배포하기 등) |
| `default` | `--well` 면 + `--line-2` 테두리 | 일반 행동 |
| `primary` | `--well` 면 + `--sub` 테두리(강한 테두리) | 대화상자 확인 등 |
| `ghost` | 투명, `--sub` 글자 | 취소, 해제, 보조 |
| `link` | 투명, `--acc-ink` 글자, 올리면 밑줄 | 다른 화면으로 가는 링크 |
| `quiet` | 28px, 투명 + `--line` 테두리 | 표·목록 행 안에서 반복되는 버튼 |

크기는 `sm` 32 / 기본 40 / `lg` 48이다.

### 알림 `Notice`

- 상태색 테두리 + 옅은 바탕 + 아이콘. 제목 한 줄에 설명은 두 줄까지 쓴다.
- tone: `success` · `warning` · `error` · `info` · `now`(배포 대기처럼 할 일을 알릴 때).

### 알림 띄우기(토스트)

- 화면 위 가운데에 뜬다. 패널 색 면에 상태색 테두리와 아이콘을 둔다.
- 완료·경고·오류는 문구로 정한다.
- 되돌리기 알림은 10초 동안 남고, Z 키를 함께 안내한다.

### 입력 `Input` · `Select` · `TextArea` · `Field`

- 상태: 기본은 `--well` 채움에 테두리 없음 → 올림은 `--line-2` → 쓰는 중은 `--sub` → 오류는 `--danger` → 성공은 `--ok`.
- `Field`: 라벨 13/500. 아래에 안내(ⓘ)·오류(ⓧ)·성공(✓) 문구를 아이콘과 함께 둔다.
- `Select quiet`: 28px, 투명. 표 안에서 쓴다.

## 8. 쓰지 않을 것

- 라이트 테마, 그라데이션, 글로우, 광택, 글래스모피즘
- 모든 카드에 깔린 옅은 그림자, 카드 안 카드, 아이콘을 둥근 칸에 넣은 장식
- 알약 배지 남발, 한쪽만 두꺼운 색 테두리 카드
- 사이드바·탭·필터·차트의 파랑, 색으로 정답을 암시하는 판단 버튼
- 12px 미만 글자, 700·800 굵기, 32px 넘는 숫자
- 정보 글자에 `--faint`, 흐리게 보이려고 쓰는 `opacity`
- 원문 노출, 마감·SLA·심각도·담당자·결재 기능
